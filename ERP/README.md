# 🏭 MazirApp — ERP (Enterprise Resource Planning) Жүйесі

> **ERP (Кәсіпорын Ресурстарын Жоспарлау)** — мейрамхананың барлық ішкі ресурстарын, материалдық құндылықтарын, қызметкерлер құрамын, қаржылық ағындарын, тағамдардың өзіндік құнын (калькуляция/BOM), сатып алуларды және сыртқы есеп жүйелерімен (Odoo ERP, iiko Cloud) байланысын қамтамасыз ететін кешенді басқару платформасы.

## 🧩 ERP Негізгі Модульдері

### 1. 📦 Қойма және Қалдықтар Есебі (`modules/warehouse/`)
- **Шикізат және тауарлар есебі (`stock_items`):** Әр тауардың өлшем бірлігі (кг, л, дана), ағымдағы қалдығы, критикалық минимум шегі (`min_stock`) және сатып алу бағасы.
- **Инвентаризация (`inventory/`):** Қалдықтарды нақты санау, артық/кем шығуларды реттеу.
- **Қозғалыс журналдары (`stock_movements`):** Кез-келген кіріс (`in`), шығыс (`out`), бүліну/есептен шығару (`waste`), ревизия (`correction`) құжат түрінде сақталады.

### 2. 🧾 Технологиялық Карталар мен Калькуляция (`modules/warehouse/recipes/`)
- **Bill of Materials (BOM):** Мәзірдегі әрбір тағамның (мысалы: "Чизбургер") құрамындағы ингредиенттер нормасы (мысалы: сиыр еті — 0.150 кг, ірімшік — 0.030 кг, бөлке — 1 дана).
- **Дайын тағамның өзіндік құны:** Ингредиенттердің сатып алу бағасына байланысты автоматты түрде тағамның базалық өзіндік құнын (Cost of Goods Sold — COGS) есептейді.
- **Автоматты шегеру (`integrations/stock-utils.ts`):** Тапсырыс "completed" статусына өткен кезде барлық ингредиенттер қоймадан автоматты түрде шегеріледі.

### 3. 🚚 Жеткізушілер және Сатып Алу (`modules/warehouse/suppliers/`)
- **Жеткізушілер карточкасы (`suppliers`):** БИН, байланыс телефондары, мекен-жайы, банктік реквизиттері.
- **Сатып алу тапсырыстары (`purchase_orders`):** Қоймада тауар азайғанда жеткізушіге тапсырыс құжатын құру (Draft -> Sent -> Received), тауар келгенде қоймаға кіріс жасау.

### 4. 👷 Қызметкерлер мен Кадрлық Есеп (HR) (`modules/workers/`)
- **Қызметкерлер профилі (`staff_profiles`):** Әкімші (owner), менеджер, аспаз, кассир, даяшы, жеткізуші рөлдері.
- **Жұмыс уақытының табелі (`attendance/`):** Келу (Check-in) және кету (Check-out) уақытын тіркеу, нақты істелген сағаттарды (`hours_worked`) есептеу, кешігулер мен демалыстарды бақылау.
- **Жалақы параметрлері:** Сағаттық мөлшерлеме (`hourly`), бекітілген айлық (`fixed`) немесе түсімнен пайыз (`percent`).

### 5. 📈 Қаржылық Аналитика және Бақылау (`modules/analytics/`)
- Күнделікті, апталық және айлық түсім динамикасы (Recharts интерактивті графиктері)
- Тапсырыстар саны, орташа чек мөлшері
- Ең көп сатылатын тағамдар (ABC анализі)

### 6. 🏛️ Зал және Үстелдер Топологиясы (`modules/tables/`)
- Залдардың орналасу картасы
- Үстел нөмірлері, сыйымдылығы (орын саны), орналасқан аймағы (VIP, Терраса, Негізгі зал)
- Үстелге арналған жылдам QR кодтар генерациясы

## 🌐 Сыртқы ERP Интеграциялары

### 1. Odoo ERP Интеграциясы (`integrations/odoo-api.ts`)
- **Технология:** Odoo JSON-RPC 2.0 API протоколы арқылы жұмыс істейді.
- **Мүмкіндіктер:**
  - Odoo серверіне аутентификация (`getOdooUid`)
  - MazirApp-та орындалған тапсырыстарды автоматты түрде Odoo-ға **Sale Order (сату құжаты)** ретінде экспорттау (`sendOrderToOdoo`)
  - Odoo қоймасымен синхронизация

### 2. iiko Cloud POS/ERP Интеграциясы (`integrations/iiko.ts`)
- **Технология:** iiko Cloud Server API
- **Мүмкіндіктер:**
  - Авторизация токенін алу (`getIikoToken`)
  - iiko-тан номенклатураны, санаттарды және бағаларды импорттау (`syncIikoMenu`)
  - Түскен онлайн/киоск тапсырыстарды iiko кассасына жіберу (`sendOrderToIiko`)

| Маршрут | Әдіс | Сипаттамасы |
|---|---|---|
| `/api/warehouse/inventory` | `GET`, `POST` | Қойма қалдықтарын алу және жаңа шикізат қосу |
| `/api/warehouse/deduct-stock` | `POST` | Тапсырыс идентификаторы бойынша рецептуралық шегеру жасау |
| `/api/warehouse/recipes` | `GET`, `POST` | Тағамның ингредиенттер құрамын сақтау |
| `/api/warehouse/suppliers` | `GET`, `POST` | Жеткізушілер мен сатып алу тапсырыстары |
| `/api/iiko/sync-menu` | `POST` | iiko жүйесінен мәзірді синхрондау |
| `/api/iiko/send-order` | `POST` | Тапсырысты iiko терминалына экспорттау |

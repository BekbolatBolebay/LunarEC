# Contributing to LunarEC 🚀

## Қош келдіңіз! (Welcome)

LunarEC — polyglot open-source ERP/CRM жобасы. Барлық контрибьюторларды қуана қабылдаймыз!

## Қатысу жолдары (How to Contribute)

### 1. Issue ашыңыз
- Bug → Bug Report шаблонын қолданыңыз
- Жаңа мүмкіндік → Feature Request шаблонын қолданыңыз

### 2. Fork & Branch
```bash
git fork https://github.com/BekbolatBolebay/LunarEC
git checkout -b feature/your-feature
```

### 3. Код стандарттары
- **TypeScript**: ESLint + Prettier
- **Rust**: `cargo fmt && cargo clippy`
- **Go**: `gofmt`
- **Python**: `black` + `ruff`

### 4. Pull Request
PR шаблонын толтырып жіберіңіз.
